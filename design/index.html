Same site, three ways to make it look less generated

Each option is the real site with every feature intact: filters, map, history, Statistici, export, RSS, English, install. Only the stylesheet changes. Use the yellow bar at the top of each page to switch between them, or go back to the current look ("Actual").

What makes the current version read as AI-made

  • Teal accent, Inter font, 14px rounded cards with soft shadows: the default look of generated dashboards.
  • Emoji used as icons (📍 🎯 🗺️ 🔗 🗑).
  • A coloured stripe down the left edge of every card, and tinted pill badges.
  • A row of floating "KPI tiles", a pulsing green dot, frosted-glass overlays.
  • Everything boxed in its own card, so nothing has more weight than anything else.

Fixed in all three, and in the current look too: emoji replaced by a consistent line icon set, and list previews skip "Bună ziua," so the first line says what the report is about. The full text is unchanged in the detail view.

Option A

Serviciu public

Looks like a well-made public-service website. Plain, trustworthy, very readable.

  • Black header, underlined links, square corners, real 2px borders instead of shadows.
  • Larger text (17px), Source Sans 3, yellow keyboard focus.
  • Reports are rows divided by rules; status is a strong uppercase tag.
  • Figures shown as plain numbers with a coloured rule, not tiles.

Best for: older users, trust, accessibility. Trade-off: less dense; can feel official even though the site is unofficial.

Option B

Registru

A working tool, like a dispatcher's console or a good issue tracker. Colour is used only for status.

  • Slim graphite header, IBM Plex Sans, monospaced ticket numbers, times and counts.
  • Compact rows: about twice as many reports on screen.
  • Figures in one status-bar strip; square map clusters.
  • The detail view reads like a record sheet.

Best for: people who check often: journalists, local councillors, active neighbours. Trade-off: smaller text, less friendly at first sight.

Option C

Aplicație

Follows the phone's own conventions, so it feels like an app people already know.

  • System font (San Francisco / Roboto), grey ground, grouped white lists with hairlines and chevrons.
  • Search field and segmented controls in the native style; one blue accent.
  • On phones: large title and a tab bar at the bottom.
  • The detail view is a sheet of grouped sections.

Best for: phone users, an installed app. Trade-off: the most familiar, so the least distinctive.
